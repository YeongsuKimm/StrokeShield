# Personal calibration recordings (not committed)

Put `.json` files downloaded from `http://localhost:5173/?record=1` here, then run `pnpm calibrate`.
Everything in this folder except this README is gitignored: recordings are landmark data of real people.
To share, use the team drive; to commit a consented recording as a regression fixture, copy it to
`src/lib/calibration/fixtures/recordings/`. Full guide: docs/CALIBRATION.md.
